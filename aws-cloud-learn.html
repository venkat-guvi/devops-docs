Introduction to Cloud Computing & AWS

What is Cloud Computing?

Cloud computing is the on-demand delivery of computing services — servers, storage, databases, networking, and software — over the internet with pay-as-you-go pricing.

💡 Simple Idea: Instead of buying and maintaining physical data center servers, you rent virtual computing resources online from Amazon Web Services (AWS).
💳

Pay-As-You-Go

No upfront hardware capital expenditure. Pay only for the exact compute time and storage you consume.

📈

Elastic Scalability

Instantly scale resources up or down automatically based on real-time application traffic demand.

🌐

High Availability

Deploy applications across multiple global data centers to ensure fault tolerance and 99.99%+ uptime.

AWS Global Infrastructure Components

🌍 Regions

Geographic locations around the world (e.g., us-east-1 N. Virginia, ap-south-1 Mumbai) containing multiple isolated data center clusters.

🏢 Availability Zones (AZs)

One or more discrete physical data centers inside a region with redundant power, networking, and connectivity.

AWS IAM (Identity and Access Management)

Secure Access Control

AWS IAM securely controls authentication and authorization for users, applications, and services interacting with your AWS resources.

👤

IAM Users

Individual identities created inside your account representing employees or services with long-term credentials.

👥

IAM Groups

Collections of IAM users. Attaching permission policies to a group grants access to all member users.

🎭

IAM Roles

Temporary permission credentials assumed by users or AWS services (e.g. EC2 assuming a role to read S3 buckets).

📄

IAM Policies

JSON document definitions explicitly specifying allowed or denied actions on specific AWS resource ARNs.

// Sample IAM JSON Policy Document
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["ec2:DescribeInstances", "ec2:StartInstances"],
    "Resource": "*"
  }]
}

Amazon EC2 Instance Management

Virtual Servers in the Cloud

Amazon Elastic Compute Cloud (EC2) provides resizable, on-demand virtual compute capacity in the cloud.

Component Description
AMI (Amazon Machine Image)Pre-configured template containing OS, application server, and software packages.
Instance TypeHardware specification defining CPU cores, RAM size, storage performance, and networking speed.
Key PairAsymmetric security key pair (Public stored on EC2, Private `.pem` file stored locally for SSH login).
Security GroupStateful virtual firewall regulating inbound and outbound port traffic.
Instance StoreTemporary, ephemeral block storage physically attached to the host server.

Auto Scaling & Elastic Load Balancing (ELB)

High Availability & High Traffic Management

Ensure application fault tolerance by combining automated instance scaling with load balancing.

📈

Auto Scaling Groups

Automatically launches or terminates EC2 instances based on custom CloudWatch metric thresholds (e.g. CPU > 80%).

⚖️

Elastic Load Balancer (ELB)

Distributes incoming web traffic across multiple healthy targets across multiple Availability Zones.

Load Balancer TypeProtocol LayerBest Use Case
Application Load Balancer (ALB)Layer 7 (HTTP/HTTPS)Web applications, microservices, container routing
Network Load Balancer (NLB)Layer 4 (TCP/UDP)Ultra-high performance, low latency, static IP addresses
Gateway Load Balancer (GWLB)Layer 3 (IP Gateway)Third-party virtual network appliances and firewalls

Amazon Storage Services (S3, EBS, EFS)

🪣

Amazon S3 (Object Storage)

Managed object storage designed for 99.999999999% (11 9s) durability. Stores unlimited files (photos, videos, logs) in global buckets. Supports static site hosting.

💽

Amazon EBS (Block Storage)

Persistent block storage volumes attached to a single EC2 instance. Ideal for OS boot drives and relational database storage (gp3, io2, st1).

📁

Amazon EFS (File Storage)

Fully managed POSIX-compliant elastic file system shared concurrently across hundreds of EC2 instances over NFS protocol.

🗄️

AWS Managed Databases (RDS & DynamoDB)

🐘 Amazon RDS (Relational SQL)

  • Managed SQL database engine (MySQL, PostgreSQL, MariaDB, Oracle)
  • Automated backups, multi-AZ replication, software patching
  • Structured data schemas with foreign key relationships

⚡ Amazon DynamoDB (NoSQL Key-Value)

  • Fully managed serverless NoSQL database
  • Single-digit millisecond latency at any scale
  • Schema-less tables containing JSON items and attributes

Amazon VPC & Cloud Networking

Virtual Private Cloud (VPC)

An isolated virtual network dedicated to your AWS account. Allows complete control over IP address ranges, subnets, route tables, and network gateways.

VPC ComponentRole
Public SubnetSubnet associated with a route table targeting an Internet Gateway (IGW). Holds web servers.
Private SubnetSubnet isolated from direct internet access. Uses NAT Gateways for outbound-only connectivity. Holds databases.
Internet Gateway (IGW)VPC component enabling bidirectional communication between public instances and the internet.
Security GroupStateful virtual firewall applied at the EC2 instance level. Automatic response return traffic.

Route 53 DNS & CloudFront CDN

📖

Amazon Route 53

Scalable Cloud Domain Name System (DNS) web service. Manages domain registration, latency routing, health checks, and automatic failover.

⚡

Amazon CloudFront

Global Content Delivery Network (CDN) that caches web content at worldwide Edge Locations to deliver low-latency responses to users.

Serverless Lambda & AWS CI/CD Services

AWS Lambda (Serverless Compute)

Run code without provisioning or managing servers. Lambda automatically executes code in response to events (e.g. file upload to S3) and scales continuously.

AWS CI/CD Developer Suite

🔨

AWS CodeBuild

Fully managed build service that compiles code, runs unit tests, and produces ready-to-deploy build artifacts.

🚀

AWS CodeDeploy

Automates application deployments to EC2 instances, Lambda functions, or ECS container services.

🔄

AWS CodePipeline

Continuous delivery service that models, visualizes, and automates software release stages.
