DevSecOps & Shift-Left Security Principles

Integrating Security Early in the Lifecycle

DevSecOps embeds automated security audits, vulnerability scanning, and compliance checks into every stage of the software development lifecycle from line 1 of code.

⬅️

1. Shift-Left Security

Catch security vulnerabilities early during local development and PR builds instead of post-production.

🤖

2. Automation First

Integrate automated SAST, DAST, and container scanners into CI/CD pipelines to block insecure builds.

🔑

3. Least Privilege

Restrict IAM permissions and container privileges to the minimum required runtime scope.

Static Code Analysis (SonarQube)

Continuous Code Quality & Security Inspection

SonarQube performs Static Application Security Testing (SAST) on source code to catch bugs, vulnerabilities, and code smells without executing code.

🚧

Quality Gates

Defines hard build failure rules (e.g. zero critical vulnerabilities, >80% code coverage). Fails CI/CD pipelines automatically if unmet.

🪲

Bugs vs. Vulnerabilities

Distinguishes logic errors that cause app crashes (Bugs) from security flaws exploited by attackers (SQL Injection, hardcoded tokens).

# sonar-project.properties
sonar.projectKey=myapp
sonar.projectName=MyApp Production
sonar.sources=.
sonar.host.url=http://localhost:9000
sonar.login=my_secret_sonar_token

Dependency Vulnerability Scanning (Snyk)

Securing Open-Source Packages

Modern applications rely heavily on external open-source packages. Snyk scans third-party libraries (npm, pip, Maven) for known CVE vulnerabilities.

Container & IaC Security Scanning (Trivy)

Lightweight & Fast Security Scanner

Trivy scans container images, filesystems, Git repositories, Kubernetes clusters, and IaC manifests for vulnerabilities and leaked secrets.

# Essential Trivy Security Commands
$ trivy image nginx   # Scan Docker container image
$ trivy fs .   # Scan local filesystem directory
$ trivy k8s cluster   # Scan active Kubernetes cluster workloads
$ trivy config .   # Scan Terraform/K8s IaC configuration files
$ trivy fs --security-checks secret .   # Scan for leaked API keys/tokens

Secrets Management (HashiCorp Vault)

Secure Storage & Dynamic Secret Engine

Never hardcode API keys, database credentials, or TLS certificates in code. HashiCorp Vault provides central encryption, access policies, and dynamic temporary credential generation.

# Vault Secrets Engine CLI
$ vault server -dev   # Start dev server
$ vault kv put secret/db password=admin123
$ vault kv get secret/db   # Retrieve secret
# Vault Policy Example (ACL)
path "secret/*" {
  capabilities = ["read"]
}

Kubernetes & Cloud Infrastructure Hardening

🛡️

Pod Security Standards

Disallow root container execution (runAsNonRoot: true), enforce read-only root filesystems, and restrict capabilities.

🌐

Network Policies

Implement default-deny network ingress/egress rules allowing only authorized microservice-to-microservice traffic.

🔑

RBAC Authorization

Use Kubernetes Role-Based Access Control to enforce least-privilege permissions on cluster resources.

OWASP Top 10 Web Vulnerabilities

The 10 Most Critical Web Application Security Risks

The Open Web Application Security Project (OWASP) identifies the primary security risks facing modern cloud applications.

OWASP RiskDescription
A01: Broken Access ControlUsers acting outside intended permissions (accessing unauthorized data/admin APIs).
A02: Cryptographic FailuresWeak or missing data encryption in transit (HTTP instead of HTTPS) or at rest.
A03: Injection (SQLi / Command)Unsanitized user inputs executed directly as SQL queries or system commands.
A04: Insecure DesignMissing threat modeling or architectural security flaws.
A05: Security MisconfigurationUnnecessary default credentials, open S3 buckets, verbose debug logs in prod.
A06: Vulnerable & Outdated ComponentsRunning third-party libraries with known CVE exploits.
A07: Identification & Auth FailuresWeak password policies or missing multi-factor authentication (MFA).
A10: Server-Side Request Forgery (SSRF)Web app fetching remote resources without validating user-supplied URLs.

OWASP Security Testing Tools (ZAP & Dependency Check)

⚡

OWASP ZAP (DAST Scanner)

Dynamic Application Security Testing (DAST) scanner that probes live web apps for SQLi, XSS, and header flaws.

$ zap-cli quick-scan http://example.com
🔍

OWASP Dependency-Check

CLI utility that scans project dependencies against the National Vulnerability Database (NVD).

$ dependency-check.sh --scan .
