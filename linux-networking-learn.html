Operating System Fundamentals

What is an OS?

An Operating System is the core software that acts as a bridge between users and hardware. It ensures applications run smoothly by managing resources like CPU, memory, storage, and connected devices.

⚙️

Process Management

Runs multiple programs simultaneously without crashing, deciding which process gets CPU time.

$ music + browser running simultaneously
🧠

Memory Management

Controls RAM allocation per program, prevents memory overlap, and frees memory on close.

$ virtual memory enables multitasking
📁

File System Management

Organizes data in files and folders — enabling create, open, save, and delete operations.

$ /home/user/Documents/report.txt
🖨️

Device Management

Communicates with hardware (keyboard, printer, speakers) via special programs called drivers.

$ printer driver → sends job data

What is Linux?

🐧 The Linux Kernel

Linux is a free, open-source operating system family built upon the Linux Kernel — the brain of the OS that manages how the computer interacts with hardware. Created by Linus Torvalds in 1991, its source code is open for anyone to explore and improve.

💡 Linux runs on virtually all hardware — Windows PCs, Macs, tablets, Chromebooks, phones, and even gaming consoles. It's one of the most versatile operating systems ever built.
🆓

Free & Open Source

Anyone can view, modify, and distribute the source code. This openness has built a massive global contributor community.

🔒

Secure by Design

Linux's permission model and separation of user/root access makes it inherently harder to compromise than many other OS types.

🖥️

Distributions (Distros)

Ubuntu, Debian, CentOS, Fedora, Arch — different "flavors" of Linux bundled with different tools and package managers.

⚡

Powers the Internet

The majority of web servers, cloud platforms (AWS, GCP, Azure), and DevOps infrastructure runs on Linux.

📂

Linux File System

/ — The Root Directory

Everything in Linux lives under / — the root. Every file and directory, regardless of physical disk location, is a child of root. Understanding the hierarchy unlocks how Linux works.

/── root of the entire filesystem
├──/binessential binaries (ls, bash, cp)
├──/sbinsystem admin binaries (root only)
├──/bootkernel + bootloader (vmlinuz, grub)
├──/devdevice files (sda, null, tty)
├──/etcsystem-wide config files (passwd, fstab)
├──/homepersonal directories for each user
├──/libshared libraries for /bin and /sbin
├──/mntmanual mount point (external drives)
├──/mediaauto-mounted removable media
├──/optthird-party optional software
├──/tmptemporary files (cleared on reboot)
├──/usruser programs and system resources
├──/varvariable data — logs, caches, databases
├──/procvirtual FS — running process info
└──/sysvirtual FS — kernel & device info
⚠️ Never modify files in /boot carelessly — mistakes can make your system unbootable.

Users, Groups & Permissions

👤 Users

Each user has a unique UID. Root = 0. System users = 1–999. Local users start from 1000.

👥 Groups

Collections of users that share common permissions. Every user has a Primary Group (auto-created) and can join Secondary Groups.

Process & Service Management

What is a Process?

Every command you run creates a process — a running instance of a program, tracked by a unique PID (Process ID). Linux tracks up to 5-digit PIDs and reuses them when exhausted.

🖥️

Foreground Process

Runs in the terminal, blocks other commands until done. Use Ctrl+C to stop it.

$ ls -la /var/log
🌙

Background Process

Runs independently, freeing the terminal. Append & to any command to background it.

$ long-task.sh &
CommandPurpose
ps auxList all running processes
kill <PID>Terminate a process gracefully
kill -9 <PID>Force kill a stubborn process
bg <job>Move stopped job to background
fg <job>Bring background job to foreground

Networking Fundamentals

What is a Network?

A network is two or more devices linked together to share resources, exchange files, or communicate. The Internet is a global network of networks — a vast infrastructure linking millions of computers worldwide using the standardized Internet Protocol Suite (TCP/IP).

☁️

Virtual Operation

Networks allow remote work, cloud computing, and distributed systems.

📡

Large-scale Integration

Thousands of devices, services, and users connected seamlessly.

⚡

Quick Response

Modern networks react instantly to changing conditions and topology.

🔐

Data Security

Networks enable encryption, firewalls, and access control at scale.

OSI Model & TCP/IP

OSI Model (Open Systems Interconnection)

Created in 1984 by ISO, the OSI model breaks network communication into 7 layers, each serving a specific purpose. Data flows down the stack on the sender side and up on the receiver side.

7
Application
User-facing services — email, web, file transfer
HTTP / FTP / SMTP
6
Presentation
Data translation, encryption, compression
SSL / TLS / JPEG
5
Session
Manages sessions between applications
NetBIOS / RPC
4
Transport
End-to-end data delivery, error checking
TCP / UDP
3
Network
Routing data packets across networks
IP / ICMP / ARP
2
Data Link
Node-to-node delivery, MAC addressing
Ethernet / WiFi
1
Physical
Raw bits over hardware cables and signals
Cables / Radio
📌 TCP/IP simplifies this into 4 layers: Application → Transport → Internet → Network Access. It's the actual model used on the internet today.

IP Addressing & Subnetting

🌍 Public IP

  • Assigned by ISP
  • Used to communicate externally
  • Traceable to a location
  • Static (fixed) or Dynamic (changes)

🏠 Private IP

  • Assigned by your router
  • Used inside local network only
  • Not visible on the internet
  • Ranges: 192.168.x.x, 10.x.x.x

✂️ Subnetting

Subnetting divides a large network into smaller sub-networks for better performance, security, and management. Like splitting a large classroom into smaller study groups.

Network Troubleshooting

Your Network Toolkit

When something goes wrong on the network, these tools help you diagnose, trace, and fix connectivity issues from DNS resolution failures to port availability checks.

📡

ping

Check if a host is reachable over the network using ICMP packets.

ping guvi.in
🔍

nslookup

Query DNS servers to resolve domain names to IP addresses.

nslookup guvi.in
🗺️

traceroute

Display the path packets take to reach a destination, hop by hop.

traceroute guvi.in
🔌

netstat

Show active connections, routing tables, and network interface stats.

netstat -tulnp
🗺️

nmap

Discover hosts and open ports on a network. Essential for security auditing.

nmap guvi.in
📦

tcpdump

Capture and analyze raw network traffic on an interface.

tcpdump -i eth0
📋

host

Simple DNS lookup — shows IP for a hostname and hostname for an IP.

host guvi.in
🔗

ifconfig / ip

Configure and display network interface info. ip a is the modern version.

ip addr show
🚪

telnet

Test if a specific port is open and accepting connections on a server.

telnet guvi.in 443
