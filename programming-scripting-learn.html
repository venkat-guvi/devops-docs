Shell Scripting Fundamentals

What is Shell Scripting?

A Shell Script is a text file containing a sequence of commands executed by the shell interpreter. Instead of manually typing commands one by one, scripts automate repetitive system administrative tasks.

⚡

Advantages

Portable across Linux platforms, saves time, easily automates deployments, backups, and system monitoring tasks.

⚠️

Considerations

Slower than compiled languages, creates a subshell process per command, and syntax errors can be costly if unverified.

#!/bin/bash   # Shebang: Path to interpreter
echo "Hello DevOps!"   # Display output to screen
💡 Always grant execution permissions before running a new script: chmod +x script.sh, then run with ./script.sh.

Control Flow & Loops in Bash

Decision Making & Iteration

Automate repetitive server tasks by combining conditional logic (if-elif-else) with iteration structures (for, while, until).

# If-Else & File Check
if [ -f "/var/log/syslog" ]; then
  echo "Log file exists"
else
  echo "Log missing!"
fi
# For Loop Over List
for server in web01 web02 db01; do
  echo "Checking $server status..."
  ping -c 1 $server
done

Modular Code & Debugging Techniques

Functions improve readability and avoid duplicate logic. Use execution flags to debug script failures.

function backup_logs() {
  echo "Creating backup for $1..."

File Handling, Logs & Error Handling

Parsing Logs & Production Exception Handling

Never let automation scripts crash unexpectedly in production. Wrap dangerous network/file operations inside try-except blocks.

# Safe Log Processing & Error Handling
try:
  with open("/var/log/nginx/access.log") as f:
    logs = f.readlines()
    print(f"Analyzed {len(logs)} log entries.")
except FileNotFoundError:
  print("Log file not found! Skipping...")

OS Interaction & Subprocess Execution

Executing CLI Commands via Subprocess

Use Python's subprocess.run() module instead of outdated os.system() to safely invoke system binaries like kubectl, docker, or git.

import subprocess

# Run CLI command and capture output safely
result = subprocess.run(["docker", "ps"], capture_output=True, text=True)
print(result.stdout)
