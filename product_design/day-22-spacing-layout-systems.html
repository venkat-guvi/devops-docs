in UI Design

01 Why Spacing is Underrated

Spacing is the invisible architecture of your UI.

Why Beginners Miss It

Colors and fonts feel exciting. Spacing feels boring — but it does most of the work.

Empty space feels "unfinished" to a novice. Pros know: space = confidence.

Bad colour is obvious instantly. Bad spacing is felt, not seen.

Luxury brands (Apple, Notion, Linear) use MORE space, not less.

If your UI feels "off" but you can't explain why — check spacing first.

02 Spacing & Readability

Bad spacing is not just ugly — it is a usability failure.

Three Key Areas

Scanability — Users scan in an F-pattern. Spacing creates visual breaks so the eye knows where a new section begins.

Touch Targets — Apple min: 44×44px. Google: 48×48px. Too small = mis-taps = frustrated users.

Cognitive Load — Cramped elements make the brain work harder. Spacing = natural groupings = less effort.

Line height for body text: minimum 1.5× the font size.

03 Spacing System Fundamentals

Stop guessing. Pick a scale. Stick to it.

What a System Gives You

Consistency — every screen feels cohesive, even across designers.

Speed — no micro-decisions ("14px or 16px?"). Just pick the nearest value.

Developer handoff — clean, repeatable values. No back-and-forth.

New designer onboarding — they can match the system immediately.

A spacing system is a constraint that sets you free.

04 The 8pt Grid System

Every value is a multiple of 8: 8, 16, 24, 32, 40, 48, 64…

Why 8?

Most screen densities (1×, 2×, 3×) divide cleanly by 8. Multiples of 8 always render crisp — no blurry half-pixels.

Sub-grid Tip

Use 4px for internal element spacing (icon padding, badge gap). Use 8px for layout spacing (card margins, section gaps).

In Figma: set nudge amount to 8. Shift+nudge = 8px jump.

05 Spacing Scale & Visual Rhythm

Consistent spacing creates flow. Random spacing creates friction.

The Social Distance Rule

Think of spacing like social distance between people. Elements that are closely related sit close together. Unrelated sections stand far apart.

4px — Icon padding, badges (intimately connected)

8px — Icon-to-label gap, list item spacing

16px — Card padding, form field gaps ★ BASE

32px — Major section gaps

64px — Page-level, hero sections

Use no more than 5–6 spacing values on a single screen.

06 Layout Structure

Every element is a box. Understand the box model.

Three Layers

Content — the actual thing: text, image, or icon.

Padding — breathing room INSIDE the element (between content and border).

Margin — space OUTSIDE the element (between this and its neighbours).

Container Rules

Desktop max-width: 1200–1440px. Never stretch full screen.

Mobile: 16px horizontal padding minimum. Non-negotiable.

Tablet: 24–32px padding.

Desktop: 40–64px padding — users sit further from the screen.

Left-align body text. Centre-align hero, modals, and empty states.

07 Visual Hierarchy Using Spacing

Spacing alone can guide the eye — no colour or size change needed.

Gestalt Law of Proximity

Things close together = perceived as related. Things far apart = perceived as separate. No borders or colours needed — just correct distance.

The Pro Move

A heading with 8px below it and 32px above it visually "belongs" to the section below. The large gap cuts its connection to what came before.

Squint test: hierarchy should still be visible at low vision.

08 White Space & Negative Space

White space is not wasted space — it is an active design element.

Types

Micro — letter-spacing, line-height, small gaps. Massive impact on readability.

Macro — large empty areas between sections. Creates breathing room.

Active — intentionally placed to direct attention or emphasise something.

The Paradox

Adding more content often makes users see LESS of it. Reduce content + add whitespace = users notice and remember more.

When stuck: double your current whitespace and see what happens.

09 Layout Consistency Across Screens

Spacing that adapts intelligently to each screen — without breaking consistency.

Quick Reference

PropertyMobileTabletDesktop
Page margin16px24px40px+
Section padding32px48px80px
Card padding16px24px32px
Button height48px44px40px

Buttons are LARGER on mobile (48px) than on desktop (40px) — touch needs more area than a cursor.

10 Common Spacing Mistakes

These are the errors that make a portfolio look student-level.

Spot & Fix

✗ Inconsistent card padding — cards look slightly different for no reason.

✗ Content touching the screen edge — less than 16px horizontal margin.

✗ Section gap = element gap — nothing groups, nothing separates.

✗ Squashed buttons — 16px wide but only 6px tall. Untappable.

✗ Ignoring OS safe areas — content under iPhone notch or Android nav bar.

✓ Same-level cards: identical padding (pick 16px or 24px and stick to it).

✓ Always 16px from the screen edge on mobile. No exceptions.

✓ Sections: 32–48px gap. Elements within section: 8–16px gap.

✓ Buttons: 24px horizontal padding, 44–48px height.

11 Before vs After

No new colours. No new fonts. Just spacing.

The 7-Step Transformation

Audit — list every gap. Are they random or systematic?

Round to 8pt — snap every value to the nearest multiple of 8.

Fix touch targets — every interactive element ≥ 44px tall.

Add section breathing room — at least 32px between major sections.

Standardise card padding — pick one value, apply everywhere.

Add screen edge margins — 16px minimum on mobile sides.

Review groupings — related close (8px), unrelated far (32–48px).

CSS Custom Properties

: root {

--space-1: 4px; /* icon padding, badge gap */

--space-2: 8px; /* icon↔label, list gap */

--space-4: 16px; /* BASE — use most often */

--space-6: 24px; /* card padding, grid gap */

--space-8: 32px; /* section separation */

--space-12: 48px; /* hero, desktop margin */

--space-16: 64px; /* page-level spacing */

}
.card { padding: var(--space-4); gap: var(--space-2); }
