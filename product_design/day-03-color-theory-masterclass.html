Part 1: Color Theory Fundamentals

What is Color Theory?

Color theory is the study of how color interact and the guidelines for how to combine them effectively

1.1 The Color Wheel

The color wheel is the foundational tool for understanding how colors relate to each other. It was first developed by Sir Isaac Newton in 1666 and has since become the backbone of visual design.

Primary Colors

These are the building blocks — they cannot be created by mixing other colors.

Red#FF3B30Yellow#FFCC00Blue#007AFF

Secondary Colors

Formed by mixing two primary colors in equal parts.

Orange (R+Y)#FF9500Green (Y+B)#34C759Violet (B+R)#8B5CF6

Tertiary Colors

Created by mixing a primary with an adjacent secondary color. Examples include red-orange, yellow-green, blue-violet, etc.

Red-Orange#FF5E3AYellow-Orange#FFAB00Yellow-Green#8BC34ABlue-Green#00BCD4Blue-Violet#5C6BC0Red-Violet#C2185B

Warm vs. Cool Colors

🔥 Warm ColorsRed, Orange, Yellow and their variations.Evoke energy, passion, urgency, warmth.Visually advance — they appear closer to the viewer.Used in: CTAs, food brands, sale banners, alerts.❄️ Cool ColorsBlue, Green, Violet and their variations.Evoke calm, trust, professionalism, stability.Visually recede — they appear farther from the viewer.Used in: Tech, finance, healthcare, productivity apps.

Color psychology studies how hues influence human perception, emotion, and decision-making. As a UI/UX designer, understanding this is critical to communicating the right message.

Part 2: Color Combinations & Harmony

Color harmony refers to aesthetically pleasing color relationships. These are defined by their position on the color wheel. Understanding these helps you create palettes that feel intentional, not accidental.

2.2 The 60-30-10 Rule

A timeless design principle borrowed from interior design. It creates a balanced, professional-looking palette in any project.

60%Dominant ColorBackgrounds, large surfaces, primary UI sections. Usually neutral or brand color.
30%Secondary ColorCards, sidebars, secondary sections. Complements the dominant color.
10%Accent ColorCTAs, highlights, interactive elements. Should stand out immediately.

Part 3: Accessible & Consistent Color Systems

3.1 Why Accessibility Matters

Accessibility is not optional — it is a design responsibility. Approximately 1 in 12 men and 1 in 200 women have some form of color vision deficiency. Designing accessibly means your product works for everyone.

Key Statistics300 million people worldwide experience color blindnessRed-green color blindness (Deuteranopia/Protanopia) is the most common formWeb accessibility is required by law in many countries (ADA, EN 301 549, EAA)Accessible design improves usability for ALL users — not just those with disabilities

3.2 WCAG 2.1 Contrast Guidelines

WCAG stands for Web Content Accessibility Guidelines. It defines minimum contrast ratios between foreground (text/icon) and background colors. These are measured using a luminance-based formula.

LEVELCONTRAST RATIOAPPLIES TOSTATUS
AA Normal4.5 : 1 Dark grayBody text, UI text under 18pt (or 14pt bold)✓ PASS
AA Large3.0 : 1 Medium grayLarge text 18pt+ (or 14pt bold), UI components, icons✓ PASS
AAA Normal7.0 : 1 BlackEnhanced — recommended for critical text content✓ PASS
AAA Large4.5 : 1 Light GrayEnhanced — recommended for large text, decorative icons✓ PASS
FailBelow 3.0Light GrayDoes not meet minimum accessibility requirements✗ FAIL

3.4 Building a Consistent Color System

A color system (also called a design token system) ensures colors are applied consistently across your entire product. It removes ambiguity and scales with your team.

Step 1: Define Your Base Palette

Start with 1-2 brand colors. Then generate a full scale from 50 (lightest) to 900 (darkest) for each color. Tools: Colors, Adobe Color, Figma Plugins (Paletter 4, Color Styles).

50#EEF2FF100#E0E7FF300#A5B4FC500 (Base)#6C63FF700#4338CA900#1E1B4B

Map your base palette to semantic roles. This way, if your brand color changes, you update it in one place.

Part 4: Iconography — Expressing Through Icons

Icons are the visual shorthand of UI design. A well-designed icon communicates meaning instantly — without words. But poorly chosen or inconsistent icons create confusion and erode trust.

4.1 What is an Icon?

An icon is a simplified visual symbol that represents an action, object, or concept. Icons sit at the intersection of metaphor, culture, and design convention. They only work when users already know what they mean — or can guess correctly.

Types of Icons in UI Design

TYPEDESCRIPTIONEXAMPLES
RepresentationalLook like the thing they represent. Highest recognition, least ambiguity.House → Home, Magnifier → Search, Envelope → Email, Bell → Notifications
SymbolicAbstract representations using convention. Require learned meaning.Hamburger menu, Share icon (arrow pointing up), Refresh arrows
Arbitrary (Learned)No inherent visual connection. Meaning is purely convention-based.Floppy disk → Save, Bluetooth logo, WiFi signal bars
UniversalGlobally recognized across cultures with very high consistency.Play ▶, Pause ⏸, Stop ⏹, Heart ♥, Star ★, Plus +, X to close

4.2 Icon Styles in UI Design

Consistency in icon style is as important as consistency in color. Mixing styles within the same product creates visual noise and signals poor design quality.

Filled IconsThe shape is completely filled with color.Best for: Active states, selected navigation tabs, primary actions.Examples: Material Icons (filled), SF Symbols (filled), Font Awesome (solid)Outlined IconsOnly the stroke/outline of the shape is visible. No fill.Best for: Inactive states, secondary actions, minimalist UIs.Examples: Google Material Outlined, Phosphor Icons (Regular), Heroicons (Outline)Duotone IconsTwo-tone icons — usually a bold shape with a lighter secondary shape or shadow.Best for: Feature illustrations, onboarding screens, marketing UI.Examples: Phosphor (Duotone), Streamline DuotoneFlat IconsSimple, no depth, no shadows. Clean and modern.Best for: Mobile apps, digital-native products, dashboards.Examples: Feather Icons, Remix Icons, Lucide

1. Clarity — The Icon Must Be Instantly Understood

Reduce detail to the absolute minimum that still communicates meaning

Use familiar metaphors that your target users already know

Test with users — if they can't guess the meaning in 3 seconds, redesign

📌
07 / 09

2. Consistency — Icons Must Belong to the Same Family

Use the same stroke weight across all icons (e.g., always 1.5px)

Match corner radius — all sharp, all rounded, or all mixed — consistently

Keep optical size consistent. A circle may need to be slightly larger than a square to look the same size visually

Never mix filled and outlined icons at the same hierarchy level

📌
08 / 09

3. Scalability — Icons Must Work at All Sizes

Design on a grid — common sizes: 16x16, 20x20, 24x24, 32x32, 48x48

At 16px and below, remove fine detail — it becomes visual noise

At 48px and above, add more detail for visual richness

Always export as SVG — never PNG for UI icons

📌
09 / 09

4. Accessibility — Icons Should Not Stand Alone

Always pair icons with labels in navigation and critical actions

Provide aria-label in code for screen readers: aria-label='Search'

Do not rely on color alone to communicate meaning (e.g., error icon should have both red color AND an 'X' shape)

Minimum touch target size: 44x44px on mobile (Apple HIG) / 48x48dp (Material Design)

4.4 Icon Sizing & Grid System

Icons are designed on a grid to ensure optical alignment and consistent sizing. Most systems use a base grid of 24px with a 2px padding inside.

SIZEUSE CASECONTEXTNOTES
