What is DevSecOps?

DevSecOps (Development + Security + Operations) is a practice that integrates security into every stage of the software development lifecycle.

Simple idea: Instead of adding security at the end, we include it from the beginning.

DevSecOps Principles

Shift Left Security → Security starts early in development

Automation First → Security checks are automated

Continuous Monitoring → Systems are always monitored

Least Privilege Access → Give only required permissions

Secure by Design → Build secure applications from the start

Example: Code is scanned for vulnerabilities before deployment.

Security in CI/CD Pipelines

Security checks are added in pipeline stages.

Pipeline Flow:

Code → Build → Test → Security Scan → Deploy

Example:

Scan code using SonarQube

Scan dependencies using Snyk

Scan Docker images using Trivy

Sample Pipeline Idea:

Build → Test → Code Scan → Dependency Scan → Image Scan → Deploy

HashiCorp Vault is a tool used for securely storing and managing secrets.

Secrets include:

Passwords

API keys

Tokens

Certificates

Simple idea: Vault stores sensitive information securely instead of keeping them inside code.

Why Use Vault?

Secure secret storage

Dynamic secrets

Encryption services

Access control

Audit logging

Install Vault

Ubuntu:

sudo apt install vault

Verify:

vault --version

Start Vault Dev Server

vault server -dev

Vault Authentication

Login:

vault login

Store Secrets

Store database password:

vault kv put secret/db password=admin123

Retrieve secret:

vault kv get secret/db

Policies define access permissions.
